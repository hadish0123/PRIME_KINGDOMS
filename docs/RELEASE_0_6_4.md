# PRIME KINGDOMS 0.6.4

Medium character quality and action stability milestone; Android version code 10.

Reduces groom tessellation, beard density and facial subdivision while preserving the rig, armor, skin materials and motion clips. The character review enforces a 210,000 triangle ceiling. Balanced graphics remains the default; FPS values are targets, not physical device benchmarks.

Blocks jumping and turning during committed actions, stops residual movement when an action starts, checks space before lying down, and sheathes the physical sword before entering prone instead of teleporting it. Interrupted actions cancel the queued posture change.

Validate actual rendering, drawing, sheathing, attack contact, crawling, clearance, horseback locomotion and dismounting before release. This is not a claim of zero bugs or completed empire gameplay. Production worlds and accounts are preserved.

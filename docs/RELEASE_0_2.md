# PRIME KINGDOMS 0.2 — Third-person village

Native Android development APK with a rigged third-person character, movement, sprint, jump, orbit camera and touch controls. Includes a streamed 65.536 × 65.536 km terrain world and a starter village with exactly eight soldiers and five villagers.

Create an account in the app, or use ENTER WORLD to sign back in. Account, village, NPC identities and player position are persisted by the Railway PostgreSQL backend. Existing players keep their home and starter population on later visits.

The included village screenshot is captured from the real native 3D renderer using a test account fixture. NPC presentation patrols are basic; full independent NPC simulation, combat, kingdom growth, PRIME's god powers and the seven Legends are future work. Graphics are a stylized prototype, not final photorealistic or AAA artwork.

This APK is for testing and uses a development signing certificate. Rebuilt development APKs may need the previous installation removed; sign back into the same account afterwards to restore server progress. A stable production keystore will be configured for release builds. Physical Android device performance has not yet been measured. SHA256SUMS.txt records the exact APK checksum.

3D models by Quaternius (CC0 1.0); see client/assets/ATTRIBUTION.md.
